# Happy Holidays from Anna Lee

Interactive 3D L-fold paper-cut holiday greeting card built with React, TypeScript, Vite, and Three.js custom gouache shaders.

**Live Card:** https://leejiwon-designs.github.io/happy-holidays-3dcard/

## Features
- **L-Fold Pop-Up Card**: Scalloped crimson postage-stamp cover with click-bouncy 3D ribbon bows that unfolds to reveal layered paper-cut winter scenes for Toronto, Seoul, Vancouver, and Brussels.
- **24 Interactive 3D Ornaments**: Drag and drop or tap to decorate 36 ledges around the 7-tier sliceform tree, with auto-decorate and clear controls.
- **High-Res MP4 Export**: Captures a 360-degree showcase video with synchronized synthesized holiday music via WebCodecs (`mp4-muxer`) or high-bitrate fallback recording.
- **Procedural Audio & Custom Shaders**: Real-time WebGL gouache lighting, stipple paper-tooth post-processing, falling snow particles, and Web Audio chime/music synthesis.

## Development


Build for production:
